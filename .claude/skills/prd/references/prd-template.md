확정 여부: **초안**

## 문제 / 범위

누구의 어떤 문제를 해결하고 어떤 동작을 바꿀지 쓴다.

## 비범위 / 보존 동작

바꾸지 않을 동작과, 회귀로 보호할 것(응답 모양, 정렬, 권한, 빈 상태)을 적는다.

## 결정

| ID | 결정 | 근거 |
| --- | --- | --- |
| D-1 | 사용자가 정한 것 | 사용자 답변 또는 `docs/rules/NN` |

현재 코드에서 본 사실과 사용자 제품 결정을 구분한다.

## 완료 조건

| ID | 상황·입력 → 행동 → 관찰할 결과 | 확인 방법 |
| --- | --- | --- |
| AC-1 | 구체적인 상황에서 행동하면 관찰할 수 있는 결과 | 어떤 테스트·화면·API로 확인하는지 |

## 검증 범위

| 영역 | 적용 | 이유 |
| --- | --- | --- |
| tests | required | `npm run verify`와 새 동작의 테스트 |
| api | required / not-applicable | API·데이터·권한 영향 |
| ui | required / not-applicable | 화면·흐름 영향 |

not-applicable은 영향이 없다는 근거가 있을 때만 쓴다. 도구가 없어서·귀찮아서는 근거가 아니다.

## 질문

미해결 제품 결정을 적는다. 없으면 "미해결 질문 없음".
