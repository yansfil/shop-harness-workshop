# 계약 규칙

- 요청·응답 모양은 zod 스키마가 정하고 경로는 `ROUTES`·`ENDPOINTS` 한 곳에 둡니다. api와 web이 같은 스키마를 씁니다.
- 고객용 요청 스키마에는 고객 ID 필드를 두지 않습니다.
- 금액은 `MoneySchema`(정수 원)로 받습니다.
- 스키마를 바꾸면 api의 mapper, web의 화면, 관련 테스트를 한 번에 고칩니다.
- 화면이 계산해야 하는 값(합계, 상태 표시 여부)은 서버가 응답에 담아 줍니다.
