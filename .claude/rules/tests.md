# 테스트 규칙

- 기존 테스트의 `expect(...)` 기대값을 바꿔서 통과시키지 않습니다. 실패하면 코드를 고칩니다. 동작을 정말 바꿔야 하면 사람에게 먼저 확인받고 새 동작을 새 테스트로 적습니다.
- API 통합 테스트는 `tests/support/test-app.ts`의 `createTestApp()`(메모리 DB, `FixedClock`)로 실제 HTTP 요청을 보냅니다. 시간은 `new Date()`가 아니라 `clock`으로 고정합니다.
- 기대값은 PRD나 규칙 문서에서 가져옵니다. 현재 구현의 출력을 복사해 정답으로 삼지 않습니다.
- 테스트를 지우거나 `skip`·`only`로 돌리지 않습니다.
- 한 테스트는 보호하는 동작 하나를 이름에 적습니다. 위임만 하는 함수에는 테스트를 붙이지 않습니다.
