# order-cancel 인터뷰

요청: 고객이 주문을 취소할 수 있게 해 주세요.
상태: **PRD-ready**

현재 코드에서 본 사실: 주문 상태는 결제완료 → 배송준비 → 배송중 → 배송완료뿐이고 취소는 없다.
재고는 주문할 때 `InventoryService.decreaseForOrder`가 줄이고, 되돌리는 길은 없다.
쿠폰과 포인트는 이 레포에 없다.

## 질문과 답

| 번호 | 질문 | 답 |
| --- | --- | --- |
| D-1 | 어느 상태에서 취소할 수 있나요? | 결제완료와 배송준비만. 배송중부터는 취소할 수 없다 |
| D-2 | 누가 취소하나요? | 주문한 고객 본인만. 관리자 취소는 이번에 하지 않는다 |
| D-3 | 취소하면 재고는요? | 주문 수량만큼 되돌린다. 입출고 이력에 "취소 복구"로 남겨 관리자가 알아볼 수 있게 한다 |
| D-4 | 결제 금액은요? | 가짜 결제라 실제 환불은 없다. 화면에는 "교육용 가상 결제라 실제 환불은 없어요"를 적는다 |
| D-5 | 같은 취소 요청이 두 번 가면요? | 두 번째도 성공으로 답하고, 재고는 한 번만 되돌린다 |
| D-6 | 취소한 주문은 어떻게 보이나요? | 상태는 "주문취소". 관리자 목록에서도 뱃지로 보이고 다음 단계 버튼은 없다 |
| D-7 | 실수로 누르는 것은요? | 확인 창을 거친다. 취소는 되돌릴 수 없다고 먼저 알린다 |
| D-8 | 관리자가 상태 변경 화면으로 취소를 시킬 수 있나요? | 아니요. 상태 변경은 다음 단계로만 넘긴다. 취소는 재고 복구가 함께라서 취소 요청으로만 한다 |
| D-9 | 쿠폰·포인트는요? | 이 레포에 없으므로 해당 없음 |

## 미해결

없음. `prd` Skill로 이어 간다.
